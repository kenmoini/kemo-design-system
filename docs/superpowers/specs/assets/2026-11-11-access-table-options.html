C · Card with segmented filters

Each tab is one outlined card: a header with the count, description and "Add"; a filter row of segmented toggles plus search; bulk actions appear inline in the footer next to the pager. Quietest; fewer controls on screen at once.

Shared: TanStack Table v9 under Park's Table (sortable headers, column/global filters, row selection, client pagination), Park Checkbox in the first column, Park Menu for the ⋯ actions, Park Dialog for "Add". The same arrangement repeats on Groups, Roles, Permissions, Service accounts and OAuth apps with their own columns. Click the arrangement you prefer; the Overview, Audit, OIDC and Settings tabs come next as playbacks.
