Deployments · the list page

Inside the console shell with "Deployments" active. Every option has the same scope row under the page header (Clusters and Namespaces as multi-select pickers, "All" by default, last choice remembered by the host) and the same table built on the Access DataTable: name links to the detail page, status with a dot, ready replicas, labels as chips, age, a ⋯ menu. They differ in where the status and label filters live and how rows are arranged.

C · Rail + rows grouped by cluster

Same rail as A, but rows sit under collapsible cluster headers with their counts, and a "Group by cluster / Flat" toggle. Reads well when several clusters are in scope; costs a grouping feature in the table.

Shared: statuses are Available / Progressing / Degraded / Paused (from the Deployment conditions and `spec.paused`); labels filter as `key=value` chips; the row menu offers Scale…, Restart, Pause/Resume, Edit YAML, Delete; clicking a name goes to the detail page. Click the arrangement you prefer; the detail page comes next.
